
The CAD files showing the Loco-Manipulation Challenge testbed are given here. The dae, fbx, and usd files can be used for loading the apparatus into other CAD or or simulation softwares. The "LocoManipulationTestbed" folder contains the surface images referenced by the fbx and dae files. 

*Note:* These CAD files contain the shapes of the apparatus, but do not have accurate mass, inertial, friction, and contact parameters for accurate physics. 

The "Light Bulb" folder contains the stl file for the 3D-printed lightbulbs that will be used instead of glass lightbulbs in the testbed.

The "Can Crusher" folder contains the stl files for the can-holder, can-crusher mechanism, an example can, and an example can task bin. 

The "Cabinet Handles" Folder  contains the stl files for the handles used on the cabinet doors and drawers, with a details document giving number and placement.
